# 🌿 Kairós Residencial Sênior

Site institucional criado para a **Kairós Residencial Sênior**, uma casa de repouso para idosos localizada na Vila Santo Estefano. O projeto apresenta o residencial, seus cuidados e sua rotina, e facilita o contato das famílias pelo WhatsApp.

> *"Mais que um lugar, um lar que acolhe."*

---

## 📋 Sobre o projeto

O site é uma *landing page* de página única (one-page), com design acolhedor e responsivo. O objetivo é transmitir confiança e carinho às famílias que buscam um lugar seguro para seus entes queridos, além de facilitar o agendamento de visitas.

## ✨ Funcionalidades

- **Menu de navegação fixo** com rolagem suave entre as seções
- **Menu responsivo** com botão "hambúrguer" para celulares
- **Seção de cuidados** com os diferenciais do residencial
- **Seção "Um dia na Kairós"** com a rotina de manhã, tarde e noite
- **Perguntas frequentes** em formato de acordeão
- **Formulário de contato** que envia a mensagem direto pelo WhatsApp
- **Botão flutuante do WhatsApp** disponível em toda a página
- **Animações de entrada** (*reveal*) ao rolar a página
- **Boas práticas de SEO e acessibilidade** (meta description, `aria-label`, `lang="pt-BR"`)

## 🛠️ Tecnologias utilizadas

- **HTML5**: estrutura semântica
- **CSS3**: estilização e responsividade
- **JavaScript (Vanilla)**: menu mobile, animações e formulário
- **Google Fonts**: Fraunces e Nunito

## 🚀 Como executar

Não é necessário instalar nada. Basta seguir os passos:

1. Clone o repositório:
```bash
   git clone https://github.com/miguelassis-del/Site-Kair-s-Residencial-Senior.git
```
2. Entre na pasta do projeto:
```bash
   cd Site-Kair-s-Residencial-Senior
```
3. Abra o arquivo `index.html` no seu navegador.

Se preferir, use a extensão **Live Server** do VS Code para visualizar as alterações em tempo real.

## 🌐 Seções do site

| Seção | Descrição |
|-------|-----------|
| **Início** | Apresentação e chamadas para agendar visita ou falar no WhatsApp |
| **Cuidados** | Cuidado humanizado, ambiente seguro, equipe qualificada e qualidade de vida |
| **Rotina** | Como é um dia na Kairós |
| **Dúvidas** | Perguntas frequentes sobre visitas, valores e atividades |
| **Contato** | WhatsApp, endereço, Instagram e formulário de contato |
